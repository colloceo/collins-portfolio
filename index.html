UniExamHelper — AI-Powered Exam Assistant

UniExamHelper is a modern web application that helps university students solve exam questions using AI. Students can upload images, PDFs, documents, or type questions directly into a chat-style interface and receive detailed, step-by-step answers powered by Groq's Llama 3.1 model. The platform features OCR for handwritten/typed images, multi-file analysis, conversation history, export tools, and a sleek dark UI. Built with React + TypeScript, it delivers fast, intelligent, and highly accessible exam support across all devices.
